# Roadmap

Graphic Packs is the first feature of **citron-mods-by-yngvifreyr1810**, not the limit of the project. The goal is a PC-focused Citron fork with easier mod management, useful graphics controls and quality-of-life improvements.

## Beta v0.1

- Cemu-inspired Graphic Packs navigation and community catalogue.
- Compatibility filtering by installed game version and Build ID.
- Native TOTK NX Optimizer / UltraCam settings.
- Compact library Add-ons summaries with full tooltips.
- Discord Rich Presence and fork branding.

## Next priorities

- Refine per-game Graphics/Mods panels and consolidate equivalent effects into understandable options.
- Expand the reviewed catalogue with clear descriptions and version coverage.
- Improve conflict explanations and installation/recovery feedback.
- Investigate inherited rendering issues, including the observed Mario Kart 8 Deluxe white-road issue.
- Add further PC modding and quality-of-life features based on hands-on feedback.

These are directions, not promised delivery dates. Report the exact game update, Build ID, mod combination, GPU and driver when reporting an issue.
